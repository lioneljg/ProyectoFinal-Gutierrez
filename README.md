# Simulador de Reservas para Barbería

Simulador para reservar turnos en una barbería.

## Qué usa

- HTML, CSS y JavaScript
- Bootstrap para que se vea bien
- SweetAlert2 para las notificaciones
- Google Fonts

## Qué hace

- Elegir servicios
- Completar datos del cliente
- Seleccionar barbero y horario
- Guardar las reservas
- Ver las reservas hechas

## Cómo usarlo

Abrir index.html y listo.

## Archivos

- `index.html` - la página
- `css/style.css` - los estilos
- `js/script.js` - la funcionalidad
- `json/servicios.json` - datos de prueba
